# 💫 About Me:
# Hi, I'm Olamilekan 👋

Full-stack developer in Winnipeg, finishing an Application Development and Delivery diploma at RRC Polytech (graduating May 2027). Open to co-op and junior developer roles, Winnipeg or remote.

I found my first client with code: a Python tool that searches the Google Places API for Winnipeg businesses with little or no web presence. I picked one, built a working site before we met, and walked in with it running.

Right now I'm deepest in back-end and cloud: REST APIs in Express and TypeScript, JWT auth with role-based access control, and serverless on AWS. On the front end, I focus on accessibility and fast, lightweight pages.

### Featured
- **[RG Prado Appliance Service](https://github.com/oajose6073/rgprado-appliance-site)**: site for a local appliance repair business. Interactive SVG diagnostic dial, Formspree lead pipeline with spam trap, under 40 KB, no build step.
- **[GracePlace Winnipeg](https://oajose6073.github.io/GracePlace-Winnipeg/Main_page/main_page.html)**: multi-page church website with a ride request service, giving page, and YouTube Data API integration. GitHub Actions builds the runtime config from repository secrets, so no API keys live in the repo.
